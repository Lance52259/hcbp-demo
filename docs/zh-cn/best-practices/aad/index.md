# 简介

## 什么是Anti-DDoS（AAD）

华为云AAD（Anti-DDoS）服务提供DDoS高防能力，帮助用户抵御大流量DDoS攻击，保障业务稳定运行。

## 最佳实践简述

本目录提供AAD服务相关的Terraform最佳实践，帮助用户快速部署和管理AAD实例及防护策略。

## 最佳实践列表

* [配置 AAD 实例的黑白名单](black_white_lists.md) - 创建AAD实例并配置IP黑白名单，实现访问控制。
