# 简介

## 什么是云性能测试服务（CPTS）

云性能测试服务（Cloud Performance Test Service，CPTS）是华为云提供的性能测试服务，帮助用户模拟真实业务场景，对云上应用进行压力测试，以评估系统的性能、稳定性和扩展能力。CPTS支持多种协议和场景，能够生成高并发压力，并提供实时监控和报告，帮助用户发现性能瓶颈，优化系统架构。

CPTS提供了灵活的测试任务管理能力，用户可以创建测试工程、测试任务和测试用例，配置并发用户数、压测时长等参数，并支持分布式压测，模拟海量用户访问。同时，CPTS与华为云其他服务深度集成，可以方便地测试云上部署的应用，实现端到端的性能验证。

通过CPTS，企业可以在上线前充分验证系统的性能表现，避免因性能问题导致的业务损失，提升用户体验和业务竞争力。
