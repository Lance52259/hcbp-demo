# 简介

## 什么是云性能测试服务（CPTS）

云性能测试服务（Cloud Performance Test Service，CPTS）是华为云提供的性能测试服务，旨在帮助用户对云上应用进行压力测试，评估系统在高并发场景下的性能表现。CPTS支持创建测试项目、配置测试任务，并模拟大量用户并发访问，帮助用户发现系统瓶颈、验证系统容量规划，确保应用在上线前具备足够的性能与稳定性。

CPTS提供了丰富的性能测试能力，包括基准并发配置、测试任务管理、实时监控与报告分析等。用户可以通过简单的配置快速发起压力测试，并根据测试结果进行性能调优。CPTS还支持与华为云其他服务集成，实现测试资源的弹性伸缩和自动化运维，降低性能测试的门槛和成本。

通过CPTS，企业可以持续进行性能验证与优化，保障业务在高并发场景下的用户体验，提升系统的可靠性与竞争力。
