# 简介

## 什么是云性能测试服务（CPTS）

云性能测试服务（Cloud Performance Test Service，CPTS）是华为云提供的性能测试服务，旨在帮助用户对云上应用进行压力测试，评估系统在高并发场景下的性能表现。CPTS支持模拟海量并发用户，提供丰富的测试场景配置和实时监控能力，帮助用户提前发现系统瓶颈，保障业务稳定上线。

CPTS提供了完整的性能测试解决方案，包括测试工程管理、测试任务编排、并发模型配置、测试报告生成等功能。用户可以通过简单的配置快速发起性能测试，并获取详细的性能分析数据，为系统优化提供依据。

CPTS还支持与华为云其他服务集成，如应用运维管理（AOM）、云日志服务（LTS）等，实现测试数据的统一监控和分析，提升性能测试的效率和质量。
