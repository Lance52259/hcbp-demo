# 简介

## 什么是文档数据库服务（DDS）

文档数据库服务（Document Database Service，简称DDS）是华为云提供的一款高性能、高可靠、高安全的云数据库服务，完全兼容MongoDB协议，支持副本集、集群和单节点等多种部署架构，适用于互联网、物联网、游戏、金融等行业的海量非结构化数据存储需求。

DDS提供自动备份、监控告警、弹性伸缩等企业级功能，支持数据跨可用区部署，确保数据的高可用性和业务连续性。同时，DDS提供细粒度的权限控制和网络隔离能力，保障数据安全。

通过DDS，您可以快速部署和管理文档数据库，无需关注底层基础设施的运维，从而专注于业务创新和发展。
