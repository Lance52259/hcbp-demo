# Introduction

## What is Cloud Performance Test Service (CPTS)

Cloud Performance Test Service (CPTS) is a performance testing service provided by Huawei Cloud, designed to help users perform stress tests on cloud applications and evaluate system performance under high concurrency. CPTS supports simulating massive concurrent users, providing rich test scenario configurations and real-time monitoring capabilities, helping users discover system bottlenecks in advance and ensure stable business launch.

CPTS provides a complete performance testing solution, including test project management, test task orchestration, concurrency model configuration, and test report generation. Users can quickly initiate performance tests through simple configuration and obtain detailed performance analysis data, providing a basis for system optimization.

CPTS also supports integration with other Huawei Cloud services, such as Application Operations Management (AOM) and Log Tank Service (LTS), to achieve unified monitoring and analysis of test data, improving the efficiency and quality of performance testing.
