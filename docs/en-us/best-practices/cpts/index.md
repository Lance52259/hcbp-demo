# Introduction

## What is Cloud Performance Test Service (CPTS)

Cloud Performance Test Service (CPTS) is a performance testing service provided by Huawei Cloud, designed to help users perform stress tests on cloud applications to evaluate system performance under high concurrency. CPTS supports creating test projects, configuring test tasks, and simulating a large number of concurrent users, helping users discover system bottlenecks, validate system capacity planning, and ensure that applications have sufficient performance and stability before launch.

CPTS provides rich performance testing capabilities, including benchmark concurrency configuration, test task management, real-time monitoring, and report analysis. Users can quickly initiate stress tests through simple configuration and perform performance tuning based on test results. CPTS also supports integration with other Huawei Cloud services to achieve elastic scaling of test resources and automated operations, lowering the threshold and cost of performance testing.

With CPTS, enterprises can continuously perform performance verification and optimization, ensuring user experience under high concurrency and improving system reliability and competitiveness.
