# Introduction

## What is Document Database Service (DDS)

Document Database Service (DDS) is a high-performance, high-reliability, and high-security cloud database service provided by Huawei Cloud. It is fully compatible with the MongoDB protocol and supports multiple deployment architectures such as replica set, cluster, and single node. It is suitable for massive unstructured data storage requirements in industries such as the Internet, IoT, gaming, and finance.

DDS provides enterprise-level functions such as automatic backup, monitoring and alarming, and elastic scaling. It supports data deployment across availability zones to ensure high data availability and business continuity. In addition, DDS provides fine-grained permission control and network isolation capabilities to ensure data security.

With DDS, you can quickly deploy and manage document databases without worrying about the operation and maintenance of the underlying infrastructure, allowing you to focus on business innovation and development.
