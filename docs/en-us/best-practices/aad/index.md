# Introduction

## What is Advanced Anti-DDoS (AAD)

Advanced Anti-DDoS (AAD) is a professional DDoS protection service provided by Huawei Cloud. It provides high-cost-performance protection for Internet-facing services, defending against large-scale DDoS attacks and ensuring service availability.
